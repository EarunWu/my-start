# My Start

一个极简、键盘友好的个人浏览器起始页。页面以搜索框、分组切换和固定导航区域为核心，适合放常用网站、临时入口和轻量工具。

## 功能

- 中心化起始页布局，导航区域固定为 5 列 x 3 行。
- 自定义分组和网页，每个分组最多 15 个网页。
- 可视化编辑模式：网页卡片抖动、删除角标、点击卡片编辑。
- 支持本地配置导入和导出。
- 支持白色、黑色、自定义图片背景。
- 支持 Google、Bing、Baidu、Grok、ChatGPT 搜索引擎切换。
- 悬停右侧搜索按钮展开半圆引擎轮盘，点击任意扇区即可切换并搜索当前输入；空输入只切换引擎。触屏点击展开，键盘聚焦搜索按钮后按 ↓ 展开并选中当前引擎，方向键选择，Home/End 跳到首尾，Enter 确认，Esc 关闭。
- 支持拖拽图片到搜索框进行图片搜索。
- 支持在搜索框粘贴 JSON，并在导航区域显示格式化预览。
- 网站卡片点击会在新标签页打开。

## 使用

这个项目是纯静态页面，不需要构建工具。

直接打开：

```text
index.html
```

也可以把 `index.html` 设为浏览器主页或新标签页扩展的目标页面。

## 数据存储

配置数据保存在当前浏览器本地：

- 分组、网站、搜索引擎等配置存放在 `localStorage`。
- 自定义背景图片存放在 `IndexedDB`，避免大图片撑爆 `localStorage`。
- 导出配置时会把背景图片重新打包进 JSON。

当前版本没有账号、登录和云同步。
