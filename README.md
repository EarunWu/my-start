# My Start

一个极简、键盘友好的个人浏览器起始页。页面以搜索框、分组切换和固定导航区域为核心，适合放常用网站、临时入口和轻量工具。

## 功能

- 中心化起始页布局，导航区域固定为 5 列 x 3 行。
- 自定义分组和网页，每个分组最多 15 个网页。
- 可视化编辑模式：网页卡片抖动、删除角标、点击卡片编辑。
- 支持本地配置导入和导出。
- 桌面组件系统：编辑模式底部点击“添加组件”，可重复添加时钟、天气和 X / 推特，分别配置、复制、删除并撤销。
- 组件可自由拖动，自动避让搜索、导航和其他组件，支持小／中／大三档尺寸；空间不足时向页面下方扩展。
- 时钟支持可搜索的 IANA 时区、数字／指针样式、12／24 小时制和秒显示；天气支持城市搜索及未来四天预报。
- 支持白色、黑色、自定义图片背景。
- 支持 Google、Bing、Baidu、Grok、ChatGPT 搜索引擎切换。
- 悬停右侧搜索按钮展开半圆引擎轮盘，点击任意扇区即可切换并搜索当前输入；空输入只切换引擎。触屏点击展开，键盘聚焦搜索按钮后按 ↓ 展开并选中当前引擎，方向键选择，Home/End 跳到首尾，Enter 确认，Esc 关闭。
- 支持拖拽图片到搜索框进行图片搜索。
- 支持在搜索框粘贴 JSON，并在导航区域显示格式化预览。
- 网站卡片点击会在新标签页打开。

## 使用

这个项目是纯静态页面，不需要构建工具。

推荐通过本地 HTTP 服务使用。Windows 安装 Python 3 后双击 `start.cmd`，它会启动服务并打开默认浏览器；使用期间保留服务窗口。也可以在终端运行：

```sh
python serve.py --open
```

将 `http://127.0.0.1:4173/` 设为浏览器主页即可。服务仅监听本机，不需要构建工具。端口已占用时会提示，不会关闭其他程序。

**从直接打开文件切换到 HTTP 时：先在原页面导出配置，再在新主页导入。** 两个地址拥有独立的浏览器存储，配置不会自动迁移；导出包含背景图片。之后保持使用相同的域名和端口。

直接打开 `index.html` 仍可使用基础功能；动态组件使用允许跨域读取的 FxTwitter 接口，仍推荐通过 HTTP 或 HTTPS 使用。网络服务的限流不会因为更换页面地址而自动解除。

## 部署到 Cloudflare

当前站点：[My Start](https://mystart.pununu.com/)。备用地址：[workers.dev](https://web-start.lite-drop.workers.dev/)。

项目通过 Workers Static Assets 发布，不需要构建页面。Node.js 和 Wrangler 仅用于部署，本地使用仍可运行 `start.cmd`。

首次部署安装工具并登录 Cloudflare：

```sh
npm ci
npx wrangler login
```

确认 `wrangler.jsonc` 中的账号 ID 和站点名称属于自己的账号，然后执行：

```sh
npm test
npm run deploy:check
npm run deploy
```

`.assetsignore` 只允许上传首页、两个样式文件、三个脚本和 Logo；配置、测试、依赖以及本地启动程序不会发布。新增运行时文件时，需要将它加入允许列表。

部署后的 HTTPS 网址拥有独立的浏览器存储。先在原页面导出配置，再在新网址导入，即可迁移网站、组件和背景图片。HTTPS 可以避免 `file://` 的安全来源问题，但不能解除 X 服务端的限流。

## 数据存储

配置数据保存在当前浏览器本地：

- 分组、网站、搜索引擎等配置存放在 `localStorage`。
- 自定义背景图片存放在 `IndexedDB`，避免大图片撑爆 `localStorage`。
- 导出配置时会把背景图片重新打包进 JSON。
- 网站图标依次尝试自定义链接、上次成功地址、网站 `/favicon.ico`、`/favicon.svg` 和 Google 图标服务，全部失败后显示首字母。图片通过 `<img>` 加载，不跨域 `fetch` 图片或网页。
- 成功图标地址在本地记忆 30 天（最多 200 个站点），图片内容由浏览器缓存；失败地址在当前页面冷却 5 分钟。同站点并发获取合并，每个候选地址最多等待 2.5 秒。“重新获取”可跳过失败冷却。
- 编辑网页时，图标链接留空表示自动获取，填写链接表示自定义。窗口会验证图片并显示预览；自动回退不覆盖自定义链接。旧 Google 服务地址默认迁移为自动模式，其他旧图标保留为自定义；图标来源缓存不随配置导出。

当前版本没有账号、登录和云同步。

## 桌面组件

进入编辑模式，在底部选择“添加组件”。无论是否处于编辑模式，都可以按住组件顶部或空白区域直接拖动并自动保存，不显示拖动柄；键盘聚焦组件后，方向键微调，Shift + 方向键每次移动 10px，Enter 或移开焦点保存，Esc 取消本次移动。配置、复制和删除按钮只在编辑模式显示，删除后的提示提供撤销。动态正文、链接和视频区域保留正常的选择、滚动与点击操作。

组件修改自动保存，并随配置 JSON 一起导入、导出。旧配置升级不会添加默认组件，也不会重置已有导航。手机宽度（680px 及以下）隐藏组件及添加入口，保留桌面配置。

天气通过 [Open-Meteo](https://open-meteo.com/) 获取，适用于个人非商业使用，无需 API Key。输入城市名称后选择具体地区；不请求设备定位。小尺寸显示当前天气，中尺寸补充今日温度范围、湿度和风速，大尺寸显示未来四天预报，统一使用摄氏度。

同城市实例共享请求，每 15 分钟刷新；网络失败时保留最近一次天气并提供重试。天气缓存独立保存在 `localStorage`，不包含在导出配置中。组件本身和时钟可离线使用，首次城市搜索及天气获取需要网络。

X / 推特组件通过 [FxTwitter API](https://docs.fxembed.com/api/introduction/) 读取公开账号动态，由页面直接渲染正文、图片、视频、引用内容及发布时间，不加载 X 官方嵌入脚本或 iframe。旧组件保存的用户名、位置和尺寸继续有效。

从接口本次返回列表中，按发布时间选择该账号最新发布的一条动态，排除回复和转发；不能保证列表包含该账号全部历史内容。图片可点击查看，视频点击播放，长文可在卡片内滚动，并提供原文及数据来源链接。文字和媒体地址经过校验后渲染。

非中文动态默认显示中文机器翻译，可通过“查看原文／查看译文”在当前卡片内切换，不会重新请求或打断视频播放。只为选中的一条动态请求中文翻译；翻译失败或超时则显示原文及提示，原文为中文时无需额外翻译请求。

每次打开或刷新页面重新请求，手动刷新同账号的所有已显示组件；只合并进行中的同账号请求，不将结果缓存到 localStorage、IndexedDB 或其他结果缓存。请求使用 `cache: 'no-store'`，但上游服务仍可能存在缓存或更新延迟。加载时禁用重复刷新，15 秒超时后提供重试；没有动态、请求失败和限流分别显示提示，不使用模拟内容或旧数据回退。

FxTwitter 为第三方服务，当前公共接口无需 API Key，支持浏览器跨域访问，无需为此新增 Cloudflare 后端。可用性和数据更新速度取决于该服务及 X 上游。配置只保存公开用户名，不保存凭据或动态内容。
